/colophon

In publishing, a colophon is an inscription at the end of a book or manuscript usually with facts about its production.

This site goes through a redesign every handful of years, but the constant has always been Hugo as the static site generator. In this current design iteration, it uses plain HTML, CSS, and very minimal Javascript, and is based on a custom theme styled with Neat CSS.

Content is written in Goldmark-powered Markdown. Code syntax highlighting is enabled by Chroma. Mathematical formulas are rendered by Mathjax. Icons are provided by Feather. Typefaces are Atkinson Hyperlegible and Jetbrains Mono, hosted locally with the help of Google Webfonts Helper.

Domain management and DNS are handled through Namecheap. Hosting is managed by Github Pages and deployed automatically via Github Actions.

This site uses Umami to help understand visitor traffic and usage patterns. Data collected is anonymous and used solely for improving the website experience.

All associated code can be found in this repository.
